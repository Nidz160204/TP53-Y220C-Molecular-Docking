# PyMOL Interaction Analysis

## Overview

The best-scoring docking poses were visualized and examined using PyMOL to investigate the predicted interactions between the ligands and the TP53 Y220C mutant.

## Analysis

Protein–ligand interactions were examined within approximately 4 Å of the docked ligand.

The analysis focused on:

- Ligand binding orientation
- Nearby amino-acid residues
- Predicted hydrogen-bond interactions
- Interatomic distances
- Overall protein–ligand interaction environment

## Ligands Analyzed

- P83 (PhiKan083)
- PK7088
- Rezatapopt (PC14586)

## Visualization

PyMOL was used to visualize the docked ligand poses and surrounding residues.

The resulting interaction images are provided in this folder.

## Interpretation

The interaction analysis provides structural context for the docking results and helps visualize how each ligand is positioned within the predicted binding region of the TP53 Y220C mutant.
