# Protein Preparation

## Target Protein

**Protein:** TP53 Y220C mutant  
**PDB ID:** 2VUK

## Structure Preparation

The TP53 Y220C mutant structure was obtained from the Protein Data Bank and prepared for molecular docking.

The receptor structure was converted into the PDBQT format required for AutoDock Vina.

## Receptor File

`2VUK_receptor.pdbqt`

## Docking Target

The prepared TP53 Y220C receptor was subsequently used as the rigid receptor for docking with the selected ligands.
