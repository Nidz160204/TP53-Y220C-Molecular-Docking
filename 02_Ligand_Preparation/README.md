# Ligand Preparation

## Ligands

Three small-molecule compounds were selected for molecular docking against the TP53 Y220C mutant:

- P83 (PhiKan083)
- PK7088
- Rezatapopt (PC14586)

## Ligand Preparation

The ligand structures were prepared and converted into PDBQT format for use with AutoDock Vina.

## Ligand Files

The prepared/best-scoring ligand poses used for downstream docking analysis are provided in PDBQT format.

- `P83_best_pose.pdbqt`
- `PK7088_best_pose.pdbqt`
- `Rezatapopt_best_pose.pdbqt`

## Software Used

- RDKit
- Open Babel
- Meeko
- AutoDock Vina
